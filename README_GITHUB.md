# نسخة GitHub Actions - تشتغل من غير لاب أو موبايل مفتوح

النسخة دي بتشتغل على سيرفرات GitHub المجانية، مش على جهازك.
بتفحص السهم كل 15 دقيقة تقريباً وقت التداول، وتبعتلك تليجرام
مباشرة لو حصلت صفقة.

---

## 1) اعمل حساب GitHub (مجاني)

روح على **github.com** ودوس **Sign up**، واملأ البيانات (إيميل،
باسورد، اسم مستخدم). مش محتاج بطاقة بنكية خالص.

---

## 2) اعمل Repository جديد

1. بعد ما تسجل دخول، دوس على **+** فوق يمين الصفحة، واختار
   **New repository**
2. حط اسم زي `cib-trading-bot`
3. خليه **Private** (أفضل، بياناتك محفوظة)
4. دوس **Create repository**

---

## 3) ارفع الملفات

1. في صفحة الـ repository الفاضية، دوس على رابط
   **"uploading an existing file"**
2. اسحب كل الملفات والفولدرات اللي جوه `github_trading_bot`
   (بما فيهم فولدر `.github` بكل اللي جواه) على الصفحة
3. لو المتصفح مايرفعش فولدر `.github` بالسحب، اعمل كده بدل:
   - دوس **Add file → Create new file**
   - في خانة اسم الملف اكتب بالظبط:
     `.github/workflows/monitor.yml`
     (GitHub هيعمل الفولدرات لوحده لما تكتب اسم فيه /)
   - افتح ملف `monitor.yml` اللي عندك بـ Notepad، وانسخ محتواه
     كله، والصقه في الصندوق
   - دوس **Commit changes**
4. اعمل نفس الحاجة لباقي الملفات: `monitor_once.py`,
   `requirements.txt`, `state.json`
5. بعد ما ترفع كل حاجة، دوس **Commit changes** في الآخر

---

## 4) ضيف مفاتيحك السرية (Secrets)

المفاتيح دي (توكن تليجرام، chat_id، Gemini) متتحطش في الكود
مباشرة - بتتحط في مكان آمن منفصل:

1. من صفحة الـ repository، دوس **Settings** (فوق)
2. من القائمة على الشمال: **Secrets and variables → Actions**
3. دوس **New repository secret** وضيف كل واحد من دول لوحده:
   - الاسم: `TELEGRAM_BOT_TOKEN`  →  القيمة: التوكن بتاعك
   - الاسم: `TELEGRAM_CHAT_ID`  →  القيمة: الـ chat_id بتاعك
   - الاسم: `GEMINI_API_KEY`  →  القيمة: مفتاح Gemini بتاعك

---

## 5) جرّب البرنامج يدوياً دلوقتي

1. روح لتبويب **Actions** فوق في صفحة الـ repository
2. لو ظهرلك رسالة تفعيل، دوس **"I understand my workflows,
   go ahead and enable them"**
3. اختار **"Live Stock Monitor"** من القائمة على الشمال
4. دوس **Run workflow** (زرار على اليمين) → في خانة force_run
   اكتب `true` → دوس **Run workflow** تاني للتأكيد
5. استنى نص دقيقة، وحدّث الصفحة - هتلاقي دائرة خضرا ✅ لو نجح،
   أو حمرا ❌ لو فيه مشكلة (دوس عليها تشوف تفاصيل الخطأ)

---

## هيشتغل إزاي بعد كده؟

من غير ما تعمل حاجة تانية، GitHub هيشغّل البرنامج أوتوماتيك كل
15 دقيقة وقت مواعيد تداول EGX (الأحد للخميس)، ويبعتلك تليجرام
لو حصلت صفقة. تقدر تتابع سجل كل التشغيلات من تبويب **Actions**
في أي وقت.

**متنساش:** أول 20 قراءة (أول ساعات) البرنامج بيكون لسه بيجمع
بيانات كفاية، مش هيبعتلك حاجة فوراً - بالظبط زي ما شفت قبل كده.
